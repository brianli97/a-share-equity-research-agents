# A股同行价值比较规则

当用户要求汇总多家 A 股财报、进行同行比较、价值排序或选择更值得深入研究的公司时：

1. 读取 `.agent-skills/a-share-peer-value-ranking/SKILL.md`。
2. 按其中链接读取输入协议、比较框架、估值政策和输出协议。
3. 先将公司证据归一为 `comparison/peer_data.json`，不要直接继承行业筛选分数，也不要按报告篇幅或措辞评分。
4. 缺失值不得记零；输出覆盖率、证据质量、置信度和情景敏感性。
5. 只有同一交易日价格和可比盈利口径完整时才启用估值排名。
6. 最终报告必须列出公司排列顺序和价值投资研究建议；排名是研究优先级，不得表述为确定收益或无条件买卖建议。
7. 默认生成 Markdown、JSON 和经过页面检查的 PDF；缺少 PDF 能力时明确说明。
