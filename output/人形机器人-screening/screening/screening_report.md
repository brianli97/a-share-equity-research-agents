# 人形机器人产业链 A 股 Top 20 筛选报告

**研究截止日：2026-10-23**  
**统一财务基期：2025 年年度报告；宇树科技使用招股说明书及上市后公告**  
**用途：研究候选池，不构成投资建议或目标价**

## 一页结论

本次将“人形机器人”定义为自定义产业链，而不是交易软件中的概念板块。纳入整机、关节/执行器、减速器、丝杠、电机与驱动、力觉/视觉传感、运动控制和工业具身平台；排除仅有泛机器人宣传、仅参股未形成业务协同、或与人形机器人缺少可核验证据的公司。

综合筛选结果显示：

- **整机最纯标的**是宇树科技，但上市仅约两个月，交易历史、估值锚和完整上市后定期报告不足，不能与成熟制造公司简单横比。
- **规模化制造与执行器平台**以三花智控、拓普集团、汇川技术为代表，优势是汽车/工业自动化制造基础强，风险是人形机器人收入仍可能较小或未单独披露。
- **高纯度核心零部件**集中在绿的谐波、双环传动、中大力德、兆威机电、江苏雷利、鸣志电器等，核心验证点是送样/研发能否转化为批量收入。
- **丝杠与线性执行器**的关注度高，但北特科技、五洲新春、恒立液压等公司的机器人收入量化证据仍有限，不能仅凭扩产规划认定订单兑现。
- **感知环节**中，柯力传感和奥比中光分别代表力觉与3D视觉；需要继续验证人形机器人客户、定点、出货和收入占比。
- 本轮没有取得同一交易日、同一口径的全体公司成交额、换手率和估值，因此“热度榜”仅采用近60日公开信息可见度代理，不输出伪精确估值榜。

## 情景敏感性

- **质量优先**：汇川技术、三花智控、拓普集团和恒立液压上升；北特科技、五洲新春等新业务候选下降。
- **成长/纯度优先**：宇树科技、绿的谐波、兆威机电、江苏雷利和奥比中光上升。
- **估值优先**：本轮不排序。缺少2026-10-23同一收盘时点的可复核估值数据，强行评分会制造虚假精度。
- **Top 20边界**：步科股份、机器人、拓斯达与美的集团、汉威科技、领益智造、秦川机床之间对“纯度/规模/财务质量”权重高度敏感。

## 局限

1. 多数公司没有单独披露人形机器人收入，业务暴露只能定性或低置信度估算。
2. 没有统一行情数据库，未对全部公司计算2026-10-23市值、换手率和估值。
3. 2026年三季报尚处集中披露期，本轮为保持可比性以2025年报为主，可能遗漏最近数月进展。
4. 供应链客户名称常受保密约束；未经公告确认的“特斯拉/宇树/华为供应商”传闻不作为事实。
5. 排名是研究优先级，不是预期收益排序。
