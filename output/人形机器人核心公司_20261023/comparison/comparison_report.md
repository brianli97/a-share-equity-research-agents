# 人形机器人核心公司同行价值比较

研究截止日：2026-10-23。共同财务期：2025年度，辅以2026年中报及最新公开信息。

## 最终研究优先级

1. 汇川技术：优先研究。业务质量、现金流、ROE与估值证据最均衡。
2. 三花智控：优秀公司，等待更好价格。主业底盘强，机器人业务仍需收入证据。
3. 拓普集团：条件式优先。现金流强，但需验证利润恢复和资本开支回报。
4. 绿的谐波：成长验证期。机器人纯度高，估值与订单持续性是主要约束。
5. 宇树科技：高成长观察。产业地位突出，但上市历史短、治理样本少、定价显著透支。

## 重要说明

- 质量优先模型排序为：汇川技术、三花智控、宇树科技、绿的谐波、拓普集团。
- 成长优先模型排序为：汇川技术、宇树科技、三花智控、绿的谐波、拓普集团。
- 最终优先级在模型基础上加入估值约束、证据长度、资本开支和失效条件。
- 五家公司行情有效日期不完全一致，估值优先场景关闭，不提供目标价。
- 本报告仅供研究，不构成投资建议。
