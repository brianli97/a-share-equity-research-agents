# A股通用分析框架

## 报告章节

1. **一页结论**：赚钱方式、增长来源、利润现金化、三项优势、三项风险、三项验证指标和数据截止日；用一张小表列出上市板块、官方行业分类、第一大业务及其收入占比，以及最相关的 3–5 个市场概念和概念业务暴露。
2. **公司画像与治理**：沿革、上市板块、官方行业分类、实控人、主要股东、激励、质押、关联关系、同业竞争和控制权风险。
3. **商业模式与产品**：客户、场景、收费、渠道、生产、收款、售后、成本、复购、定价权和资本需求。
4. **行业与竞争**：可服务市场、竞争者、价格、毛利、研发、份额及壁垒证据。
5. **收入分析**：按产品、地区、渠道、客户和季度拆分，区分销量、价格和产品结构。
6. **客户、供应商与产能**：前五大占比、关联关系、产能、产量、销量、产销率、利用率和外协。
7. **技术与研发**：研发费用率、人员、资本化、项目、专利质量、授权依赖和量产转化。
8. **利润表**：至少三年及最新一期收入、毛利率、费用率、归母与扣非利润、净利率、ROE，必要时 ROIC。
9. **现金流与利润质量**：现金利润比、收现比及经营现金流减资本开支的自由现金流近似值。
10. **资产负债表**：现金、有息负债、应收、存货、合同资产、固定资产、在建工程、商誉和合同负债。
11. **会计质量**：补助、税收优惠、投资收益、公允价值、减值、会计变更、审计意见和关键审计事项。
12. **募集资金**：用途、建设期、产能、预计收益及用利用率、转固、折旧、新产品收入验收。
13. **关联交易与股东回报**：关联销售采购、资金、担保、董事会、处罚、分红、回购和稀释。
14. **估值适用性**：仅在用户要求或可靠市场数据可得时加入，并明确日期和利润口径。
15. **战略部署与兑现度**：提取未来三项核心战略，对照实际资金来源、研发/资本开支、在建工程、人员、产能、订单、新产品收入及回报指标，区分“计划”与“已兑现”。
16. **风险、情景与跟踪表**：乐观、中性、谨慎三种情景和未来季度的 8–12 个指标。
17. **读者复核页**：给出本公司财报的建议阅读顺序、可直接搜索的关键词、关键页码、简单公式和一页结论卡，使读者能回到原文自行验证。

## 板块、行业与收入占比

报告必须单列“板块与业务构成”表，至少包括：

- **上市板块**：主板、创业板、科创板或北交所，并注明交易所。
- **官方行业分类**：优先采用交易所公司资料页或定期报告披露的行业分类，注明分类体系、分类名称、查询/报告日期和来源。若不同官方口径不一致，并列展示并解释。
- **业务构成**：采用最新年度报告的分行业营业收入；同时展示可得的分产品/服务口径。最新中期报告披露同口径数据时，可补充最新一期，但不得把半年占比与全年占比直接作趋势结论。
- **收入占比**：收入占比 = 该行业（或产品/服务）营业收入 ÷ 同期营业收入合计。至少列出各主要类别的收入、占比、同比变化和毛利率（披露时）；图表注明单位、期间、来源页码，并使列示类别与合计可勾稽。
- **市场概念**：只列与现有业务、产品用途、客户项目或明确投入有关的 3–5 个主要概念。逐项给出概念名称、对应业务、暴露占比/区间、证据、估算方法、数据期间和可信度。

概念业务暴露按以下证据等级处理：

1. **披露值/可直接计算**：公司将某项收入单列，且该业务与概念一一对应。用该业务收入除以同期营业收入，报告具体比例。
2. **估算区间**：披露口径包含多个用途或概念，只能部分映射。结合分产品收入、客户应用、重大合同/订单、子公司业务、产销量及项目投入估算上下限；展示算式和关键假设，优先给区间而不是单点数。
3. **定性相关**：只有技术储备、战略规划、研发项目、少量示范订单或没有收入拆分。写“存在相关性，暂无法可靠量化”，不得用研发投入、合同金额或项目总投资直接冒充营业收入占比。

可信度标为高/中/低：直接披露且可勾稽为高；多个官方证据可形成合理区间为中；依赖宽泛用途、单一项目或外部概念标签为低。低可信度概念不在摘要中给出精确百分比。

口径纪律：

- “上市板块”回答证券在哪类市场上市；“官方行业分类”回答监管/交易所如何归类；“业务收入占比”回答公司实际靠哪些业务取得收入。三者不得互相替代。
- 概念板块、主题标签或指数成分只是候选清单，必须注明来源和日期；概念是否成立及暴露大小仍需用公司披露的业务证据验证。
- 年报未披露分行业收入时，明确写“公司未披露分行业收入”。可用分产品/服务作为替代；需要进一步映射到概念时，只能按上述证据等级给出可复算的估算区间或定性结论。
- 概念之间可能重叠：同一收入可同时属于产业链概念、技术概念和应用场景概念。逐项暴露占比不要求也通常不应相加为 100%，必须提示不可加总；如需互斥构成，另做一张按主营产品划分且合计约为 100% 的表。
- 分部合计与营业收入不一致时，检查“其他业务”、分部间交易和抵销项；差异仍无法解释时展示差额和限制，不强行配平。

## 建议计算

- 现金利润比 = 经营活动现金流量净额 / 净利润。
- 收现比 = 销售商品和提供劳务收到的现金 / 营业收入。
- 自由现金流近似值 = 经营现金流净额 - 购建长期资产支付的现金。
- 净现金 = 现金及高流动性金融资产 - 有息负债。
- 分行业（或分产品/服务）收入占比 = 对应类别营业收入 / 同期营业收入合计。
- 应收账款占收入比例、应收周转天数、存货周转天数、跌价准备率。
- 流动比率、速动比率、资产负债率。

公式口径需写入报告；年度、季度和审计截止日后的数字不得混为同一期间。

## 行业附加指标

- 银行：净息差、不良率、拨备覆盖率、核心一级资本充足率。
- 保险：新业务价值、内含价值、综合成本率、投资收益率。
- 房地产：合同销售、有息负债、现金短债比、去化和土地储备。
- 医药：管线、临床阶段、专利期限、集采和单品依赖。
- 软件与互联网：ARR、续费率、获客成本、流失率和单位经济模型。
- 制造业：产能利用率、产销率、单位成本、原材料、折旧和在建产能。
- 消费品：同店增长、渠道库存、经销商、单店收入、复购和品牌投入。
- 周期行业：产品价格、现金成本、库存周期、供需和中周期盈利。

## 表达要求

- 先结论后证据，避免照抄原文。
- 专业词首次出现时通俗解释。
- 图表注明单位、期间和来源。
- 使用“积极信号 / 需要跟踪 / 风险”标签。
- 明确标识公司披露、计算结果和分析判断。
- 对重要结论同时给出“怎么看”和“下期验证什么”，避免只报数字。
