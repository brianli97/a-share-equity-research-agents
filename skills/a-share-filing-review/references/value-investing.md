# 价值投资分析框架

本框架用于把财报复述提升为有证据、可复核、可证伪的投资研究。价值投资不等于“低市盈率”，也不等于为公司寻找利好；核心是判断企业未来可分配现金流的质量、持续时间、再投资回报和当前价格之间的关系。

## 必须回答的八个问题

### 1. 公司究竟怎样创造价值

- 用一段话说明客户为什么付钱、公司解决什么关键问题、收入如何确认、现金如何收回。
- 区分产品销售、工程交付、订阅服务、运营收费和金融收益，避免把规模增长自动等同于价值增长。
- 指出价值链中真正决定利润的环节，以及公司对价格、渠道、客户和供应商分别有多大议价权。

### 2. 护城河是否有财务证据

从以下维度选择最相关的 3–5 项，不使用空泛的“技术领先”或“品牌优势”：

- 定价权：毛利率是否长期优于同类业务，提价后销量和客户是否稳定。
- 转换成本：客户认证、系统集成、数据迁移、售后网络或停机风险是否使更换供应商困难。
- 规模与成本：采购、制造、研发和渠道规模是否转化为单位成本或费用率优势。
- 网络、数据或生态：参与者增加是否让产品更有价值，且竞争者难以复制。
- 牌照、资源与标准：稀缺性是否持久，是否存在政策重新分配风险。
- 创新能力：研发投入是否持续转化为新产品收入、客户、毛利和现金，而不只是专利数量。

每项护城河同时写“证据”“反证”和“下期验证指标”。如果只有管理层表述，没有经营成果，标为“待验证”，不能直接列为优势。

### 3. 增长是否创造股东价值

- 拆分销量、价格、产品结构、并购、会计口径和汇率对增长的贡献。
- 比较增量利润、增量经营现金流与增量投入资本。增长依赖应收、存货、资本开支或持续融资时，要说明代价。
- 优先分析 ROIC；数据不足时用 ROE、经营利润率、资产周转、现金利润比和自由现金流近似值交叉判断。
- 区分高回报再投资、低回报扩张和维持性资本开支。订单、合同额和规划产能不能直接当作收入或价值。

### 4. 利润是否可持续

- 给出 3–5 年收入、毛利率、费用率、扣非利润、经营现金流和 ROE/ROIC 趋势。
- 把补助、公允价值、处置收益、汇兑、减值转回、税率优惠和一次性项目从核心盈利中分离。
- 对周期公司给出“正常化利润”区间：使用中周期价格、合理产能利用率和常态毛利率，不机械年化景气高点或低点。
- 对项目制公司检查完工进度、合同资产、应收账龄和现金回款；对制造业检查库存、产能利用率和价格减值。

### 5. 管理层怎样配置资本

评价最近 3–5 年经营现金的去向：

- 内生研发和资本开支是否产生收入、毛利或效率成果。
- 并购价格、商誉、整合效果和业绩承诺是否合理。
- 分红、回购和股权融资是否考虑估值与股东回报，而非只看金额。
- 股权激励考核是否真正提高每股价值，还是只扩大规模或摊薄股东。
- 大额现金与有息负债并存、频繁融资或低效理财需要解释。

给出“优秀 / 合理 / 待验证 / 较差”的资本配置判断，并列出依据与不确定性。

### 6. 股东最终能得到什么

- 计算现金利润比、自由现金流近似值、每股收益和每股净资产的长期变化。
- 关注股份总数、股权激励、可转债、定增和回购注销，避免只看总利润不看每股价值。
- 说明利润留存后是否产生更高的未来利润；高 ROE 若主要来自杠杆，也要拆解。
- 对少数股东占比较高、关联交易复杂或现金受限的公司，说明上市公司股东能实际分享的现金流边界。

### 7. 估值与安全边际

- 只有在可靠市场价格可得且注明日期时，才计算当前 PE、PB、EV/EBITDA 或自由现金流收益率；否则提供读者可代入的公式。
- 根据商业模式选择方法：稳定消费或制造可用正常化 PE/FCF；重资产和金融企业考虑 PB/ROE；多业务公司考虑分部估值；强周期公司避免使用景气顶点利润给低 PE 结论。
- 至少给出保守、中性、积极三组盈利或现金流假设，并说明关键变量，不把情景当预测。
- “安全边际”来自保守价值与市场价格的差距，也来自资产负债表、现金流和治理质量。没有价格数据时，明确写“无法判断当前安全边际”。

### 8. 投资逻辑怎样被证伪

报告必须列出 3–6 个会让核心投资逻辑失效的条件，例如：

- 核心产品份额或价格持续下降，且研发无法带来替代增长。
- 毛利率跌破合理区间，显示竞争优势消失。
- 应收和库存长期快于收入，现金流持续弱于利润。
- 高回报再投资变成低效扩产、并购减值或频繁融资。
- 实控人、关联交易、审计或监管事件破坏治理假设。

每个条件给出当前基线、预警线和下一份报告的验证方法。

## 报告中的观点层级

每个核心章节至少加入一段分析判断，回答“这意味着什么”“为什么重要”“下期看什么”。观点按以下标签表达：

- **事实**：公司或监管文件直接披露。
- **计算**：由披露数字推导，写明公式和口径。
- **判断**：结合商业模式与财务结果形成的解释，列明证据和反证。
- **估算**：依赖假设的区间结果，写明上下限、算法和可信度。

不要为了显得深入而堆砌行业常识。一个无法连接到公司数字、竞争位置或未来验证指标的观点，应删除。

## 建议新增页面

在通用财务分析之外，优先加入以下 3–5 页：

1. **价值创造地图**：客户需求 → 公司能力 → 收入 → 利润 → 现金 → 再投资。
2. **护城河证据卡**：优势、财务证据、反证、可信度和验证指标。
3. **资本配置成绩单**：研发、扩产、并购、分红、回购、融资及每股价值变化。
4. **正常化盈利与估值情景**：保守、中性、积极假设及适用估值方法。
5. **投资逻辑与证伪条件**：看多依据、主要争议、失效条件和跟踪清单。

篇幅增加必须带来新证据或新判断；不要重复一页结论、财务趋势和风险表中的相同内容。
