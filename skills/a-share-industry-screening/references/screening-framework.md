# 筛选框架

## 先定义研究对象

把用户输入归入以下一种或多种口径：

- 官方行业：证监会或交易所行业分类。
- 指数/商业行业：具有公开编制规则的分类体系。
- 概念题材：市场标签，必须核验业务兑现。
- 产业链环节：按上游、核心部件、设备、制造、渠道或应用场景建立自定义映射。

输出纳入标准、排除标准和边界案例。

## 通用维度

每个维度保留原始指标、标准化方法、分值、权重、证据等级和缺失处理：

| 维度 | 可选指标 | 解释 |
|---|---|---|
| 规模与地位 | 相关收入、市场份额、市值、产能、客户覆盖 | 判断是否是真正龙头 |
| 业务纯度 | 相关收入/利润占比、核心产品贡献 | 避免仅靠概念标签入选 |
| 成长 | 3年收入/利润复合增速、订单、产能利用率 | 区分结构增长与低基数 |
| 财务质量 | ROIC、自由现金流、毛利稳定性、净负债 | 判断增长质量和韧性 |
| 市场热度 | 成交额、换手率、覆盖度、事件热度 | 必须指定观察窗口 |
| 估值 | PE、PB、EV/EBITDA、FCF收益率 | 与行业和盈利阶段匹配 |
| 风险 | ST、商誉、质押、减持、客户集中、监管事项 | 可设风险门槛或扣分 |

## 默认排名策略

不要内置一套永久不变的精确权重。用户未指定时：

1. 分别形成龙头、热度、基本面三个分榜。
2. 综合榜以业务相关性为准入门槛，以规模与地位、成长、财务质量为主体；热度只作有限加权。
3. 展示至少三种偏好情景：质量优先、成长优先、估值优先。
4. 对 Top-N 边界附近公司做敏感性检查，并说明名次变化。

标准化优先使用行业内分位数或稳健 Z 分数，对极端值截尾。指标方向必须明确。数据缺失时按“可用指标重分配权重 + 缺失惩罚/置信度下降”处理，并同时披露，不把缺失值填成零。

## 行业适配

- 银行：净息差、不良率、拨备覆盖、核心一级资本充足率、ROE。
- 保险：新业务价值、综合成本率、偿付能力、投资收益质量。
- 地产：销售回款、净负债、现金短债比、存货与减值。
- 资源周期：成本曲线、储量、产量、商品价格敏感性和正常化利润。
- 医药研发：研发管线阶段、现金跑道、商业化产品、专利与集采风险。
- 软件/SaaS：经常性收入、续费、获客效率、研发资本化和经营现金流。
- 制造业：产能利用率、单位成本、在手订单、存货、应收和资本开支。

## 最终分层

除名次外，建议给出：

- 核心龙头：行业地位和业务暴露证据强。
- 高成长候选：增长突出但需验证持续性。
- 高热度候选：关注度高，基本面证据仍需补强。
- 价值观察：质量尚可且估值相对有吸引力。
- 风险/证据不足：存在硬风险或关键信息缺失。
